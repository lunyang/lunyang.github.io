## Key Features

**Core Library**
{: .label .label-blue }
VAE, PSO, QM, MD, and reaction models for advanced cation design

**Multi-Agent Backend**
{: .label .label-green }
FastAPI + LangGraph multi-agent system for intelligent workflows

**Web Interface**
{: .label .label-purple }
Chainlit + LangGraph frontend for intuitive interaction

**MCP Servers**
{: .label .label-yellow }
Chemistry, ORCA, Multiwfn, GROMACS, and HEMDesign integration
